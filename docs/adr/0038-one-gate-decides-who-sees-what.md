# 0038. 「誰がどの画面を見られるか」を1箇所で、描画時に決める

## Status

Accepted

## Context

ログアウトしても、画面によってはそのまま残っていた。

7つのルートに同じ5行の `beforeLoad` がコピーされていた:

```ts
beforeLoad: ({ context, location }) => {
  if (context.auth.isPending) return;
  if (!context.auth.user) throw redirect({ to: "/login", search: { redirect: location.href } });
},
```

**このガードは、サインアウトに対して一度も動いていなかった。** `beforeLoad` は遷移のときに走り、
サインアウトは遷移ではないからである。全画面から実際に試して確かめた:

| サインアウトした画面 | 行き先 |
|---|---|
| `/` `/my` `/projects/…` | `/login` |
| **`/search`** | **その場に残る** |
| **`/account`** | **その場に残る** |
| **`/dev/design-system`** | ガードすら無い |

追い出していたのは**ローダーの401**だった。`/` と `/my` は必ずAPIを叩くので401が返り、
`throw redirect()` が効く。`/account` にはローダーが無く、`/search` は検索語が空だと
早期リターンしてAPIを叩かない。つまり**守られていたのは、たまたまリクエストを投げる画面だけ**で、
ガードは飾りだった。`/dev/design-system` は5行をコピーし忘れただけで公開されていた。

同じ穴は[ADR 0036](./0036-what-each-role-is-for.md)でも一度踏んでいる
（`/admin` のロール判定が `beforeLoad` では効かず、描画側へ移した）。

## Decision

### 保証は描画時に置く

`__root` の下に `AccessGate` を1つ置き、**要件を満たさなければ保護コンポーネントも
ローダーも動かさない**。`beforeLoad` をどれだけ整理してもこの保証は作れない——
上で測ったとおり、走らないからである。

URLも `/login` に合わせる（`replace: true`。保護URLを履歴に残さない）。
**どちらが保証でどちらが見た目かをはっきりさせる**のが要点で、
これまでは「ガードが守っている」ように見えて実際は守っていなかった。

### 宣言はルートに、既定は最も厳しい側

`staticData: { access: "public" | "user" | "admin" }`。**書き忘れたら `user`。**
これまでは逆で、書き忘れると公開されていた。

`access` は**最低ランク**（順序）であって集合ではない。ロールは既に
`["member","admin","owner"]` の順序で定義してある（[ADR 0034](./0034-three-account-roles-and-a-screen-that-creates-them.md)）。
集合にすると同じ順序を2箇所で表すことになり、`owner` を書き忘れた画面が
オーナーに見えなくなる。**画面のスケールであって、プロジェクト単位のスコープ
（[ADR 0036](./0036-what-each-role-is-for.md)）とは別物**である。

公開は `/login` と `/s/$token` の2つだけ。**その一覧は表ではなくテストで持つ**——
パスの表はルートの改名で静かにズレるが、全ルートを走査するテストは腐れない。

### セッションを終える出口は1つ、そしてハードナビゲーション

`endSession()` が `signOut()` のあと `window.location.assign("/login")` する。

ルーターのローダーキャッシュ・Reactのstate・クロージャに捕まった配列——
どれも前のユーザーのタスク名を持ちうる。**1つずつ消す設計は「消し漏れが無いこと」を
レビューで担保する**が、ページを捨てる設計は**仕組みで担保する**。
共有PCでのログアウトは「次の人に見せない」ための操作なので、後者を選んだ。
代償は1日に数回のフルリロードで、このリポジトリで最も安い保証である。

**`redirect` パラメータは付けない。** サインアウトは意図した退出で、
持ち越すと**次にサインインした人が前の人の画面に着地する**。
401（セッション失効）だけが `redirect` を付ける——中断されて戻りたい、は別の出来事である。

**退会も同じ出口を通る。** 行が消えても、いま画面に描かれている状態は消えない。

### ローダーの401は残す

ゲートは「手元にセッションが無い」を、401は「手元のセッションが**もう無効**」を扱う。
**重複ではなく、別の信号**である。消すと、サーバ側で失効させられた利用者が
エラーカードの並ぶ画面を触り続けることになる。

### 未確定のときは待つ。ただし公開ルートは待たない

セッション取得中は全画面ローディング。外枠も出さない——ヘッダーは
アカウントメニューとプロジェクト切替を持ち、どちらもセッションを読むので、
早く出すと**空の切替と名前の無いボタン**が出て直後に差し替わる。

公開ルートは待たない。「公開」は**セッションを必要としない**という意味であって、
「セッションが無いことを確かめる」ではない。共有リンクは受け取った人にとって
このアプリの最初の画面で、他人のセッション取得を待たせる理由が無い。

### 公開ルートは外枠の外に描く

ヘッダーとサイドバーはサインインした人の家具である。共有ページの周りに置くと、
**受け取ったリンクを開いただけの人に、その人のものではないアプリの目次**が出る
（押せば `/login` に飛ばされるリンクが3本）。

### 権限不足は共通のメッセージ、ただし何も動かさない

URLはそのまま、ゲートが「権限がありません」を描く。追い出すと、
古いリンクを踏んだ人に「壊れている」のか「権限が無い」のか伝わらない。

文面は共通。画面ごとに書けるようにすると**書かれた画面と書かれていない画面**ができるし、
何ができないかの説明は、できる人にしか関係がない。

## Consequences

### 得たもの

- ログアウトが全画面で効く。測って確かめてある。
- ルートを足しても、既定で保護される。
- 「公開はこの2つ」が、腐らない一覧（テスト）として存在する。
- サインアウト後にメモリ上の残骸が無いことが、仕組みで保証される。

### 残っている穴

- **セッション中のロール変更は即座に反映されない。** 降格された管理者は、
  リロードするまで `/admin` の画面が残る（データはサーバが拒否する）。
  守られているのはデータであって画面で、他人の操作の反映は本人の操作とは性質が違う。
- **ログイン済みで `/login` をハードリロードすると、フォームが一瞬映る。**
  公開ルートを待たせないことの代償として意図的に許容した。例外を作ると
  「公開ルートは待たない、ただし `/login` は待つ」になり、次に足す人が毎回考える。
- **サインイン済みの人が共有リンクを開くと、ナビゲーションが消える。** 規則を1本にした帰結。
- **`staticData` の綴り間違いは型エラーにならない**（下記）。全ルートの解決結果を
  名指しで固定するテストが、その代わりの網である。

### 途中で踏んだこと（3つとも実測）

**1. `StaticDataRouteOption` をモジュール拡張してはいけない。**
このinterfaceは `@tanstack/router-core` が宣言し、`@tanstack/react-router` が再エクスポートする。
後者を拡張すると**再エクスポートを隠す別のinterface**ができ、ルート側の総称型が壊れて
`useLoaderData()` が `any` になる——12ファイルが一斉に「implicitly any」になった。
拡張はやめ、`readAccess(unknown)` で読んで絞る形にした。

**2. `useRouterState` を2つに分けると、同じナビゲーションの別の瞬間を返す。**
「この画面は公開か」と「どこへ戻るのか」を別の購読で読んだところ、
効果が**2つの異なる瞬間の組**で走った。1つのセレクタにまとめた。

**3. まとめても足りない。** ナビゲーション中、ルーターの `matches` と `location` は
一時的に食い違う——matchesはまだ `/login` を指し、searchは既に遷移先のもの（`redirect` が無い）。
正しい遷移の直後にもう一度発火して `/` で上書きしていた。
**公開画面からの送り出しは1回だけ**にした（`useRef`）。

どれも「型が通り、画面もそれらしく動く」まま間違っていた。1と2は既存のテストが、
3は新しい表のテストが捕まえた。
