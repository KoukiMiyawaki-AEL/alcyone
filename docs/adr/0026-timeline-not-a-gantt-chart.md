# 0026. 日付軸のタイムラインを作り、本格的なガントチャートは作らない

## Status

Accepted

## Context

[ADR 0024](./0024-todo-status-instead-of-completed.md)で `startAt` と `dueAt` を足した。
**日付を2つ持たせておいて、互いに突き合わせて見る手段が無いのは中途半端**である。
1行ずつ日付を読んで頭の中で並べるなら、その日付は無いのとあまり変わらない。

一方で「ガントチャート」を名乗るものが普通に持つ機能は、
**このデータには存在しない概念**を前提にしている。

| ガントの機能 | 必要なもの | alcyoneの現状 |
|---|---|---|
| 依存関係の矢印 | タスク間の先行/後続 | **入った**（[ADR 0029](./0029-task-links-and-an-editable-gantt.md)）。ただし線は描いていない |
| クリティカルパス | 依存関係 + 所要期間 | 無い |
| 進捗率のバー | 0〜100%の進捗 | `status` の4値のみ |
| リソース平準化 | 担当者と稼働 | 担当者は入った（[ADR 0028](./0028-display-names-and-assignees.md)）が、**候補が1人なので平準化する相手がいない** |
| ベースライン比較 | 計画と実績の2組の日付 | 1組のみ |

つまり本格的なガントを作るには、**まずドメインを増やす必要がある**。
そしてそのドメイン（依存関係・担当者・進捗率）は、
まだ誰のために作っているか決まっていない（[ADR 0010](./0010-alcyone-as-proving-ground.md)）。

## Decision

**日付軸のタイムラインを作る。ガントチャートとは呼ばない。**

やること: 1日1列のグリッドに、`startAt`〜`dueAt` の帯を並べる。
statusで色分けし、今日の位置を示し、**日付の無いタスクを別に一覧する**。

やらないこと: 依存関係、クリティカルパス、進捗率、リソース、ベースライン。
**データに無いものを画面に出すと、無い情報があるように見える**。

名前も「タイムライン」にした。ガントと呼べば矢印を探す人が出る。

### 日付は暦日であって時刻ではない

`2026-11-01` はタイムゾーンを持たない。ここで一番踏みやすいバグは
**ローカル時刻への変換**で、グリニッジより西の利用者にとって期限が1日前にずれる。
しかも**その人にしか起きない**ので、作った側は永久に気づかない。

計算は全てUTCで行い、`new Date(y, m, d)` と `toLocaleDateString` を使わない。
`timeline.ts` は純粋関数で、**往復して日付がずれないことをテストで固定してある**
（うるう日と月境界を含む）。

### 片方しか日付が無いタスクは1日の印にする

`startAt` だけ、あるいは `dueAt` だけのタスクは珍しくない。
もう一方を推測して帯にすると、**誰も決めていない日付が画面に出る**。
1日分の印にとどめる。

### 日付の無いタスクは落とさず、畳んで出す

軸が日付である以上、日付の無いタスクは載らない。だが黙って消すと、
**「何が予定されているか」に答えながら「何があるか」に答えたように見える**。
`<details>` で件数付きで畳んである。ボードの上限表示と同じ理由。

### ~~読み取り専用にする~~（[ADR 0029](./0029-task-links-and-an-editable-gantt.md)で覆した）

**以下の判断は覆されている。** 反論は「ピクセルを日付に戻すのは危険」だったが、
軸が固定グリッドで1列=1日である以上、変換は整数の除算であり丸めの余地が無い。
計算を純粋関数に閉じ込めて単体テストし、ドラッグ中に結果の日付を出し、
反転を防ぎ、0列のドラッグを書き込まないことで答えた。元の記述は以下に残す。



帯をドラッグして日程を変える機能は作らない。**ピクセルを日付に戻す**ことになり、
1日ずれれば利用者が触っていない期限が動く。
同じ日付は詳細フォームで曖昧さなく編集できる。

## Consequences

### 得たもの

- `startAt` / `dueAt` が初めて互いに比較できる形になった。
- 暦日の扱いを純粋関数に閉じ込め、テストで固定した。
- 表示形式が3つ（一覧 / ボード / タイムライン）になり、いずれもURLで共有できる。

### 残っている穴

- **スクロール位置が今日に寄らない。** 今日が軸上にあることは保証しているが、
  開いた瞬間に今日が見えている保証は無い（横スクロールが左端から始まる）。
- **1日1列固定。** 半年を見るとかなり横に長い。週/月の粒度切り替えは無い。
- **180日で打ち切る。** 測って決めた値ではない。
- **帯は装飾で、スクリーンリーダーには行の名前と `title` しか届かない。**
  日付の範囲を読み上げる形にはなっていない。
- **本格的なガントは意図的に未着手。** 着手条件は上表の「必要なもの」が
  ドメインに入ったとき —— 依存関係か担当者のどちらかが実装された時点で再検討する。
